# Vision quickstart

This tutorial loads a PNG image, smooths and thresholds it, labels the objects,
filters them, measures each one and writes the results. The input is generated by
an example program, so no image files need to be downloaded.

Two routes do the same job:

- the `tptbio` command line, for a single channel of a PNG or TIFF file;
- the library crate `tpt-bio-vision`, which exposes every step and more options.

## 1. Generate the input image

The example `tpt-bio-vision/examples/vision_quickstart.rs` writes a 96 x 64 grey
PNG with four bright discs on a noisy dark background, then runs the whole
analysis. From the repository root:

```sh
cargo run -q -p tpt-bio-vision --example vision_quickstart -- vision-demo
```

It creates `vision-demo/scene.png`, `vision-demo/labels.tif` and
`vision-demo/objects.csv`. The directory is a scratch folder and can be deleted.

## 2. Inspect the PNG

```sh
tptbio view vision-demo/scene.png
```

This prints the size, the pixel type, the channel count and the minimum, maximum and
mean of each channel. `view` is a data summary and does not open a window.

## 3. Threshold and label from the command line

```sh
tptbio vision segment vision-demo/scene.png -o vision-demo/cli-labels.tif \
  --min-size 10 --remove-border
```

`segment` takes Otsu's threshold of channel 0 (`--channel` selects another), keeps
foreground pixels, labels connected components with 4-connectivity by default
(`--connectivity 8` for corner neighbours), drops objects smaller than `--min-size`
pixels and drops objects that touch the border. The label image is written as 16-bit
TIFF with background 0. The command prints how many objects were found and kept.

`segment` works on the raw image. The library example below smooths the image first,
so the two routes choose different thresholds.

## 4. Measure each object

```sh
tptbio vision features --labels vision-demo/cli-labels.tif \
  --intensity vision-demo/scene.png -o vision-demo/cli-features.csv
head -n 3 vision-demo/cli-features.csv
```

The CSV has one row per object with the columns `label`, `area`, `perimeter`,
`eccentricity`, `solidity`, and the intensity columns `intensity_mean`,
`intensity_std`, `intensity_min`, `intensity_max`, `intensity_median` and
`intensity_integrated`. Leave out `--intensity` to get shape columns only.

## 5. The same analysis in the library

The example runs these steps on the generated image. The code below is an excerpt
of its `main` function, and every line appears in the example file unchanged.

```rust
let intensity: Image<f64> = channel.map(|&v| f64::from(v));
let smooth = gaussian_smooth(&intensity, 1.0)?;

let threshold = otsu_threshold(&smooth, 256)?.ok_or("image is empty or constant")?;
let mask = apply_threshold(&smooth, threshold);

let labels = label_2d(&mask, Connectivity2::Eight)?;
let kept = filter_objects(
    &labels.labels,
    &ObjectFilter { min_area: 10, max_area: None, remove_border: true },
);

let shapes = shape_features_2d(&kept.labels)?;
let stats = intensity_features(&kept.labels, &intensity)?;
```

Run it with:

```sh
cargo run -q -p tpt-bio-vision --example vision_quickstart -- vision-demo
```

Each step is a function with a clear input and output:

| Step | Function | Module |
| --- | --- | --- |
| Gaussian smoothing | `gaussian_smooth` | `spatial` |
| Global Otsu threshold | `otsu_threshold`, `apply_threshold` | `threshold` |
| Connected components | `label_2d` (4 or 8 connectivity) | `label` |
| Size and border filter | `filter_objects` with `ObjectFilter` | `objects` |
| Shape features | `shape_features_2d` | `features` |
| Intensity features | `intensity_features` | `features` |

The example also writes the label image with `save_tiff` and one CSV row per object.

## Limits of this tutorial's scope

- Only 2D images are covered. `label_2d` and the 2D feature functions reject volumes.
- `tptbio vision segment` supports one method, the global Otsu threshold. Tile-based
  Otsu and watershed exist in the library (`threshold::local_otsu_tiles`,
  `watershed::watershed`) but are not in the command line.
- The label TIFF stores 16-bit labels, so an image with more than 65535 objects
  would be clipped. The example clamps with `u16::try_from(...).unwrap_or(u16::MAX)`.
